# TopGoal Visual Profile

## Mission

Create educational image assets for Saudi elementary learners in grades 4–6. Every visual must support learning, comprehension, memory, or task completion; decoration alone is not enough.

## Audience

- Learners approximately 9–12 years old.
- Arabic-capable shell with English learning content.
- Mobile/tablet-first activity surfaces.

## Brand and pedagogy invariants

- Child-first but not preschool-like.
- Calm, clear, friendly, modern.
- Low cognitive load.
- One obvious concept/action per asset.
- Strong silhouettes and clear object identity at small card sizes.
- Visual support must be pedagogically relevant.
- Avoid embedding instructions or answer text inside the generated image when the application can render accessible HTML text.

## Preferred routes

- vocabulary noun/action → `educational-illustration` + `clear-friendly-illustration`
- picture-word match → isolated or simple-context object/action with no accidental labels
- story comprehension → `narrative-illustration` with consistent characters and setting
- listening support → contextual scene that does not reveal answers
- unit identity → restrained thematic scene or hero illustration reusable across lesson surfaces
- concept/grammar support → diagrammatic visual only when it materially clarifies meaning

## Avoid

- adult SaaS dashboard aesthetics
- neon gaming/casino styling
- preschool clip-art look
- excessive mascot usage
- crowded scenes with many competing objects
- embedded answer keys, hints, word labels, or accidental text
- culturally irrelevant stereotypes
- publisher-owned artwork imitation
- unlicensed trademarks or copyrighted character lookalikes

## Directionality

- Generated assets should normally contain no text.
- Arabic interface/help text remains HTML/UI and RTL.
- English learning text remains HTML/UI and LTR.
- If text inside an image is unavoidable, keep it exact, short, and QA it separately.

## Consistency

For recurring story characters, mascots, or unit worlds, preserve a canonical visual description and reference assets. Do not silently change age, clothing, palette, proportions, or defining traits between assets.

## QA

A TopGoal educational asset passes when:

1. the target concept is immediately recognizable;
2. it is age-appropriate for grades 4–6;
3. it does not expose the correct answer unintentionally;
4. it remains clear at activity-card size;
5. it contains no accidental text or malformed glyphs;
6. it avoids adult/corporate and preschool extremes;
7. its content is compatible with the curriculum intent and asset licensing rules.
